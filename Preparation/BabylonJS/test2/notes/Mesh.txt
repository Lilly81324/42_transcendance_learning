Meshes are created with functions under:
BABYLON.MeshBuilder.(...)
Example:
	const box = BABYLON.MeshBuilder.CreateBox("box", {width: 2, height: 1.5, depth: 3})
As seen above some things like dimensions can be decided on Creation.
ALternaticely, create a mesh object first, and then change its properties later on:
	const box = BABYLON.MeshBuilder.CreateBox("box", {}); //unit cube
	box.scaling.x = 2;
	box.scaling.y = 1.5;
	box.scaling.z = 3;
	or
	box.scaling = new BABYLON.Vector3(2, 1.5, 3);

Properties:
box.scaling.[x,y,z]
box.position.[x,y,z]
box.rotation.[x,y,z]

Combine multiple meshes into one with:
const new_mesh = new BABYLON.Mesh.MergeMeshes([mesh1, mesh2], true, false, null, false, true)
Parameter Explanation:
Array of meshes - the meshes you want to merge
Dispose source  - If the original meshes should be cleaned
Is Sum of Certices > 64k - Not for this
Mesh to merge into - Null here, we want to make a new combination
subdivideWithSubMeshes - If Mesh should be subdivided into different Meshes
multiMultiMaterials - Overwrites last parameter, subdivides Mesh into submeshes with differnent Materials

A Mesh can be copied either with:
.clone("New Object")
	Makes a copy that shares the geometry, meaning changes to one change all others
.createInstance("New Object")
	MUCH easier to render with lots of copies

You can make any 2d shape with 3d depth,
by creating a Vector3 array:
const array_name = [
	 new BABYLON.Vector3(-3, 0, -1),
	new BABYLON.Vector3(1, 0, -1),
	new BABYLON.Vector3(3, 0, 1),
	new BABYLON.Vector3(-1, 0, 1),
]
and creating a:
MeshBuilder.ExtrudePolygon{"", {shape: array_name, depth: 0.3}}

Another Example: Make a cylinder:
const circular = []
for (let i = 0; i < 80; i++) {
	circular.push(new BABYLON.Vector3(0.2 * Math.cos(i * Math.PI / 40), 0, 0.2 * Math.sin(i * Math.PI / 40) - 0.1));
}
const wheel = BABYLON.MeshBuilder.ExtrudePolygon("car", {shape: circular, depth: 0.15});
